# AppGraph

AppGraph displays the topology of different applications.

If a connection target is not in the graph response, AppGraph shows a warning
that the graph is incomplete. Expand **Show unresolved connections** to see
the owning resource ID and the target ID for each omitted connection.
Resources and connections with both endpoints present remain visible.
